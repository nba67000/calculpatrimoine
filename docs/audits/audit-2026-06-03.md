## Divergence détectée cette session

### Mineure - URLs service-public.fr basculées en service-public.gouv.fr

Toutes les URLs `service-public.fr/...` redirigent en 301 vers
`service-public.gouv.fr/...`. La redirection est propre, donc les liens
fonctionnent encore, mais c'est l'occasion de mettre à jour les fichiers
sources pour pointer directement sur l'URL canonique.

**Fichiers concernés** (ligne `service-public.fr` à remplacer par `service-public.gouv.fr`) :
- `docs/sources/plus-value-immobiliere.md` (ligne 88)
- `docs/sources/per-individuel.md` (ligne 49)
- `docs/sources/donation-droits.md` (ligne 61) - déjà en `service-public.gouv.fr` ✅

Action : Claude peut appliquer ce remplacement directement.

### Mineure - Divergence "seuil 150k€ AV" déjà corrigée mais documentation obsolète

L'audit du 2026-05-03 avait identifié une divergence MAJEURE :
`assurance-vie/fiscalite-rachat` n'implémentait pas le seuil 150 000 €.

**Vérification 2026-06-03** : la divergence est **résolue dans le code**
(`src/lib/assuranceVie.ts` lignes 34-46) - input `encoursTotalContrats`,
constante `SEUIL_ENCOURS_PFU_REDUIT = 150_000`, fonction `tauxIRPost2017`
avec prorata correct.

**Reste à corriger** : `docs/sources/assurance-vie-fiscalite-rachat.md`
ligne 66 affirme encore "DIVERGENCE MAJEURE [...] Correction à valider par
Nicolas avant implémentation". Cette note est obsolète.

Action : Claude peut appliquer ce remplacement directement.

### Mineure - Date de dernière vérification

Les 7 fichiers sources ont une date `**Dernière vérification**` antérieure
au 2026-06-03. À mettre à jour pour ceux qui ont été re-validés cette session.
